# Arduino (arduino)

Arduino is an open-source electronics platform providing hardware, software, and cloud services for the global maker and IoT developer community. The Arduino IoT Cloud REST API enables programmatic management of devices, Things, dashboards, properties, and time-series data — authenticated via OAuth2 client credentials and supported by SDKs in JavaScript, Python, and Go.

APIs.json: [https://raw.githubusercontent.com/api-evangelist/arduino/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/arduino/refs/heads/main/apis.yml)
